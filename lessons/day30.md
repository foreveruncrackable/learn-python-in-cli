# Day 30: Conclusions & Next Steps

> **Big idea:** you now know the building blocks. Skill comes from building things.

## What You've Learned
- **Basics:** variables, data types, operators, strings
- **Data structures:** lists, tuples, sets, dictionaries
- **Control flow:** conditionals and loops
- **Reusing code:** functions, modules, comprehensions, higher-order functions
- **Robust code:** debugging, exceptions, files, regular expressions
- **Organising code:** classes and objects, packages, virtual environments
- **The wider world:** web scraping, data analysis (statistics, pandas), web apps (Flask), databases (MongoDB), APIs

## A Simple Way to Make a Project
1. **Pick something tiny** you'd actually use.
2. **Write one sentence** about what it should do.
3. **Break it** into 3-5 small steps.
4. **Build one step**, run it, fix it, then move on.
5. **Save it with Git** and show someone.

## Project Ideas
- To-do list that saves to a file
- Quiz or flashcard game
- Expense tracker with a summary
- Weather app using an API
- Blog or notes site with Flask
- Data dashboard from a CSV file
- Web scraper that checks prices

## Where to Go Next
- **Web:** Django or FastAPI
- **Data science:** NumPy, pandas, Matplotlib
- **Machine learning:** scikit-learn, then PyTorch or TensorFlow
- **Automation:** scripts for files, email and spreadsheets
- **Better code:** testing with `pytest`, type hints, Git and GitHub

## Habits That Make You Better
- Code a little **every day**.
- **Read** other people's code and the official docs.
- **Break** things on purpose and read the error.
- Explain what you learned to someone else.
- Join a community: ask questions, answer questions.

## Key terms to Revisit
- **function · class · module · package · exception · API · virtual environment**
If you can explain each in one sentence, you've really learned them.

## Watch out
- Don't just keep watching tutorials; **build** something, even if it's ugly.
- Getting stuck is normal. Read the error, search it, simplify the problem.
- Don't compare your day 30 to someone else's year 5.
- **Remember:** small projects finished beat big projects abandoned.
